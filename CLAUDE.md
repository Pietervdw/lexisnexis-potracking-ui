## Commands

- `npm start` or `ng serve`: dev server on http://localhost:4200 (hot reload)
- `npm run build` or `ng build`: production build to `dist/` (default configuration is production)
- `ng test`: run all unit tests (Vitest via the `@angular/build:unit-test` builder, jsdom environment)
- `ng test --include <glob>`: run a subset of specs, e.g. `ng test --include src/app/app.spec.ts`
- `ng generate component <name>`: scaffold a component (other schematics via `ng generate --help`)

No lint command is configured; formatting is Prettier (`printWidth: 100`, `singleQuote: true`, Angular parser for `.html` files).

## Architecture

Angular 22 standalone-component app (no NgModules) generated by Angular CLI 22.3, styled with Tailwind CSS v4.

- **Bootstrapping**: `src/main.ts` -> `src/app/app.ts` (`App` root component) with `src/app/app.config.ts` providing router and global error listeners. Routes live in `src/app/app.routes.ts` (currently empty).
- **Feature structure**: features go under `src/app/features/<feature>/` with a `data-access/` subfolder for services (see `features/purchase-orders/data-access/purchaseorder-service.ts`). Keep services/side effects outside components there.
- **Components**: use `signal()` and signal-input style from Angular 22 (see `app.ts`); no `@NgModule`, no decorators beyond `@Component`.
- **Tailwind**: v4 CSS-first setup; `src/styles.css` contains `@import 'tailwindcss'`, processed through PostCSS (`.postcssrc.json` plugin `@tailwindcss/postcss`). Theme customization goes in `@theme` blocks in CSS, not `tailwind.config.js` (none exists).
- **TypeScript**: strict-ish flags enabled (`noImplicitOverride`, `noPropertyAccessFromIndexSignature`, `noImplicitReturns`, `noFallthroughCasesInSwitch`); target ES2022, project references split between `tsconfig.app.json` and `tsconfig.spec.json` (vitest globals available in specs).
- **Build budgets**: initial bundle 500kB warning / 1MB error; component styles 4kB/8kB. Lazy-load route components and avoid importing heavy libraries eagerly.
